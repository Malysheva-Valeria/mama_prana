# Mama Prana — Концепція односторінкового сайту

Студія йоги. Односторінковий (single-page) сайт у стилі брендової презентації:
мінімалізм, повітря, елегантна типографіка, атмосферні фото.

---

## 1. Фундамент бренду (з презентації)

### Палітра

| Колір                    | HEX       | Роль                          |
| ------------------------ | --------- | ----------------------------- |
| 🟦 Глибокий синій        | `#1E3A5F` | Основа, глибина, стабільність |
| 🟧 Теракота              | `#C15A34` | Акцент, енергія, тепло        |
| ⬜ Крем                  | `#EAE4D8` | Світлий фон, повітря          |
| 🩵 Приглушений блакитний | `#8FA6BB` | Вторинний, спокій             |

### Типографіка

- **Заголовки** — елегантна серифна (як «mama prana» / «LOGO PRESENTATION»),
  висококонтрастна, «модна».
- **Підписи/лейбли** — широкорозведений сан-серіф капсом (як `YOGA STUDIO`).
- **Основний текст** — спокійна серифна, подекуди курсив.

### Настрій

Багато повітря, ч/б та теплі фото, мінімалізм. Символ бренду — схід сонця
в квадраті (**енергія + стабільність = mama prana**). Промінь/дуги логотипа
можна використати як графічний елемент-розділювач.

### Напрямки студії (видно в презентації)

- **Body** — асани (sirsasana, sarvangasana, halasana… trikonasana)
- **Face Yoga** — «Elevate your beauty with face yoga»
- **Retreats** — йога-ретрити, подорож самопізнання
- **Продукти** — олійка для масажування обличчя (30 ml)
- **Akashi** (згадується на паковці)

Домен: `mamaprana.com.ua`

## 2. Структура сторінки (вертикальний скрол)

Логіка руху: **спокій → знайомство → напрямки → запрошення**.
Кожен екран — як слайд презентації, що дихає.

1. **Hero** — на весь екран. Синій фон, по центру логотип, під ним
   коротка мантра-теза (напр. «Дихай. Рухайся. Повертайся до себе»).
   Знизу делікатна підказка скролу.

2. **Філософія / Про студію** — крем-фон, велике серифне речення про підхід
   - маленький параграф. Збоку ч/б фото.

3. **Напрямки (Practices)** — Body · Face Yoga · Retreats.
   Три блоки з чергуванням кольорів (синій / теракота / крем),
   кожен з фото та коротким описом. **Серце сторінки.**

4. **Простір / Галерея** — стрічка атмосферних фото студії
   (рендер фасаду + practice-фото).

5. **Розклад / Формати** — прості картки з типами занять.

6. **CTA-запис** — теракотовий екран, велике запрошення
   «Перша практика» + кнопка/контакт.

7. **Футер** — лого, соцмережі, контакти, `mamaprana.com.ua`.

### Мікровзаємодії

Плавна поява секцій при скролі (fade/rise), делікатний паралакс на фото,
лінія-промінь з логотипа як розділювач. Нічого зайвого — стиль тримається
на просторі й типографіці.

## 3. Питання, які треба вирішити (обговоримо разом)

### A. Загальний тон / фон

- [ ] **Світлий (крем)** — легкий, повітряний, «спа»-настрій
- [ ] **Темний (синій)** — преміальніше, драматичніше
- [ ] **Чергування секцій** — синій/крем/теракота, найближче до презентації

### B. Що обов'язково має бути (окрім атмосфери)

- [ ] Кнопка запису (Instagram / Telegram / форма)
- [ ] Розклад занять
- [ ] Ціни / абонементи
- [ ] Контакти + карта

### C. Мова

- [ ] Тільки українська
- [ ] Українська + English (перемикач)

### D. Наскільки «живим» робити (анімації)

- [ ] Стримано й елегантно (делікатні появи, легкий рух) — _рекомендовано_
- [ ] Виразно й ефектно (паралакс, анімована типографіка, рух логотипа)
- [ ] Майже статично (чистий швидкий сайт)

### E. Організаційне

- [ ] Мета: імідж-візитка чи інструмент для запису?
- [ ] Чи є готові тексти / фото / розклад / ціни / контакти?
      (якщо ні — роблю «рибу»-плейсхолдери, потім заміните)
- [ ] Формат результату: один HTML-файл для браузера чи розміщення на домені?
- [ ] Референси інших сайтів, що подобаються за відчуттям

## 4. Технічний план (попередній)

- Один самодостатній `index.html` (вбудовані CSS/JS), без зовнішніх залежностей —
  легко відкрити, легко розмістити.
- Адаптивність: mobile-first, гарно на телефоні й десктопі.
- Шрифти: система/веб-безпечні або локальні файли (щоб не залежати від CDN).
- Логотип-символ відтворюємо як inline-SVG (схід сонця в квадраті).
- Плейсхолдери фото на старті → заміна на реальні знімки студії.
